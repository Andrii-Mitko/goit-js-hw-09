## 📋 Про проєкт

Вебзастосунок складається з двох інтерактивних сторінок, створених за допомогою
HTML, CSS та JavaScript.

Проєкт демонструє практичне застосування DOM API, обробки подій, роботи з
формами, браузерним сховищем та сучасного інструментарію розробки.

### Основні можливості

**1. Image Gallery**

- Відображення інтерактивної галереї зображень.
- Перегляд зображень у збільшеному форматі.
- Взаємодія з елементами галереї.

**2. Feedback Form**

- Форма зворотного зв'язку.
- Обробка введених користувачем даних.
- Перевірка та збереження стану форми в браузері.

## 🚀 Локальний запуск

Для запуску проєкту на локальному комп'ютері:

1. Клонуй репозиторій:

   ```bash
   git clone https://github.com/Andrii-Mitko/goit-js-hw-09.git
   ```

2. Перейди в папку проєкту:

   ```bash
   cd goit-js-hw-09
   ```

3. Встанови залежності:

   ```bash
   npm install
   ```

4. Запусти режим розробки:

   ```bash
   npm run dev
   ```

5. Для створення production-збірки:

   ```bash
   npm run build
   ```
